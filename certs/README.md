# Certificate Photos Directory

Place your official certificate images or scans in this directory using the filenames below. The portfolio website automatically displays them in the **Certifications & Development** section and in the high-resolution Certificate Modal viewer.

## Standard Filenames

| Certification | Filename |
|---|---|
| CCNA (Cisco Certified) | `certs/ccna.jpg` |
| CCNP ENCOR | `certs/ccnp-encor.jpg` |
| CCNP ENARSI | `certs/ccnp-enarsi.jpg` |
| Fortinet NSE 3 | `certs/fortinet-nse3.jpg` |
| Sophos Firewall Engineer | `certs/sophos-engineer.jpg` |
| SIEM/SOC Fundamentals | `certs/siem-soc.jpg` |
| Ethical Hacking Essentials | `certs/ethical-hacking.jpg` |
| Digital Forensics Essentials | `certs/digital-forensics.jpg` |

> [!TIP]
> You can also upload certificate photos directly through the portfolio interface in your browser using the **Upload Photo** button on each card or via the **Manage Certificate Photos** modal. Uploaded photos are stored locally in your browser immediately.
